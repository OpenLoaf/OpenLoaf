## 本次更新

### ✨ 新功能

- **macOS 电脑操控（实验）**：新增 `MacosObserve` / `MacosAct` 工具，让 Agent 通过专用 Helper 读取并操作 macOS 桌面，为端侧自动化打开入口
- **云任务断线续传与取消**：长时任务（图像/视频生成）在服务端持久化 —— 客户端断开后重连仍可取回结果，进行中的任务可干净取消

### 🚀 改进

- **Qwen 多模态中间件**：新适配器中间件让 Qwen 模型通过原生 vision 通道接收附件，与其他厂商走同一套流程
- **附件 tag 展开**：模型前处理更稳健，master harness 的运行时工具引导也做了收敛
- **PPTX 预览**：内嵌幻灯片渲染与交互更顺滑

### 💄 界面优化

- **工具消息 UI**：`MessageError` 错误渲染与 Office 工具壳层视觉清理；文件预览打开与 Stack header 链路更顺
- **AI Debug Viewer**：小幅布局微调

### 🐛 修复

- **云图像流程**：对积分不足、并发超限、资源耗尽等响应给出更清晰的错误提示（zh/en/ja/zh-TW 全量本地化）

### 🔧 内部

- 新增云任务 mock 基础设施和 macOS 控制相关浏览器测试
- 新增支撑 macOS 控制流程的 `fs` 路由端点
